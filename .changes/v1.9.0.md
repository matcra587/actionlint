# v1.9.0

## GitHub Actions compatibility

- Support workflow and job `cache-mode`, including reusable workflow calls.
- Support `concurrency.queue` with `single` and `max`, expression checks, and validation of incompatible cancellation settings.
- Recognize `job.workflow_ref`, `job.workflow_sha`, `job.workflow_repository`, and `job.workflow_file_path`.
- Recognize `code-quality`, `copilot-requests`, and `vulnerability-alerts` permissions with their supported access levels.
- Recognize Ubuntu 26.04, Ubuntu 26.04 Arm64, Xcode 27, Xcode 27 xlarge, and Windows 11 Visual Studio 2026 Arm64 runners.
- Refresh current Windows and macOS runner aliases while preserving explicit historical labels.

## Installation and releases

- Publish Homebrew casks and Scoop manifests alongside signed release archives and container images.
- Include prepared release notes and validate the release commit before tagging.
- Remove the automatic generated-data refresh workflow; bundled metadata remains available.
