# v1.9.1

## Fixes

- Reject mapping, sequence, and null entries in configuration `ignore` lists instead of treating them as patterns that suppress all diagnostics. Explicit empty string patterns remain supported.
- Report explicitly tagged NaN timeouts as invalid values instead of panicking.
- Preserve container volumes separately from ports for jobs and services, regardless of YAML key order.
- Respect directory boundaries when identifying projects and caching reusable workflow metadata.
- Detect potentially untrusted `workflow_run.head_branch` and `workflow_run.head_repository.owner.login` expressions embedded in scripts.

## CI hardening

- Replace Codecov with coverage summaries and downloadable HTML, XML, and Go coverage reports in GitHub Actions.
- Prepare an opt-in, isolated upload job for GitHub Code Quality coverage when the feature becomes available for this repository.
- Keep coverage summaries and downloadable reports for every test platform, including fork pull requests, without granting test jobs write permissions.
